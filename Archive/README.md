# 归档（Archive）

**状态**：占位（尚未存放内容）
**创建日期**：2026-10-09

---

## 用途

存放**不再活跃**的历史资料：已废弃的文档、旧版本设计稿、被取代的脚本与配置等。
**放入本目录即表示不再维护**，仅作追溯与参考。

## 与相邻目录的分工

| 目录 | 存放内容 | 是否维护 |
|---|---|---|
| `Docs/` | 规范、设计、指南、开发日志、问题排查记录、待办清单 | 是 |
| `Archive/`（本目录） | 已废弃 / 已停止维护的历史资料 | 否 |
| `Dist/` | 构建产物（由构建生成） | 由构建维护 |

## 规则

- 移入时用 `git mv`，**保留 Git 历史**（不要删除后新建）；
- 在文件头部注明「**已废弃（YYYY-MM-DD）**」与替代物（如有），便于读者判断；
- 本目录**不参与 CI 检查**（`bin/CheckDocs.py` 的扫描范围是 `Docs/` 与 `.agents/`），
  因此归档文件里的失效链接不会让构建失败；文件名保持原样，不要求符合 `DocumentationSpec.md` 的命名；
- 需要恢复时，从 Git 历史取回，不要直接在 `Docs/` 里重建副本。
