## 关键决定

1. **任务项不改 AST**：`ListItem` 保持 `(indent, text)`，任务识别放在 `MarkdownTask` 纯函数里。
   这样解析器不用多背一个状态，识别逻辑也能直接在无头环境单测（JavaFX 冒烟代价高）。
2. **只读复选框**：用 `Label` 显示 `☐` / `☑`，不挂点击——勾选状态是回答内容的一部分，
   允许点击等于让用户篡改历史消息（与 S1.6 的「原文为准」一致）。
3. **表格单元格用 `TextFlow` 而非 `Label`**：`Label` 只吃纯文本，行内样式会被整段丢掉；
   列宽交给 `GridPane` 按 pref 宽度计算，超宽横向滚动而不是折行（与终端 `TableRenderer` 的取舍相反）。
4. **任务符号只在无序列表生效**：有序列表的 `1.` 编号逻辑保持不变，避免 `1. [ ] x` 这种少见写法引出歧义。
