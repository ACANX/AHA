# 开发日志 2026-10-20 16:00

> 关联：issue #381 —— POSIX 发行包（ubuntu / macos）内不应包含 Windows 专属脚本 `.bat` / `.cmd` / `.ps1`
> 关联记录：`PrunePlatformScripts.py`、`CliReleasePackageLeg.yml`、`DesktopPackageLeg.yml`、`NativeImageLeg.yml`、`CliNativeImageLeg.yml`、`BuildMvnArtifactLeg.yml`、`bin/CheckScripts.py`

## 📋 任务概述

`0.1.5.00380` 的四种 ubuntu 包里，三种带着 Windows 专属脚本：

| 包 | 多余文件 |
|---|---|
| `aha-cli-jvm-…-ubuntu-amd64-jdk25.zip` | `AhaCli.bat` |
| `aha-desktop-jvm-…-ubuntu-amd64-jdk25.zip` | `AhaDesktop.bat`、`apply-update.cmd`、`AhaApplyUpdate.ps1` |
| `aha-desktop-native-…-ubuntu-amd64-graalvm25.zip` | `apply-update.cmd`、`AhaApplyUpdate.ps1` |
| `aha-cli-native-…-ubuntu-amd64-graalvm25.zip` | 无 |

`UpdateLauncher.installHelpers()` 在非 Windows 上只找 `apply-update.sh`，这些脚本在 POSIX
上不会被任何路径使用，属纯冗余内容。

## ✅ 方案（issue 建议的 A + 守卫）

**A. 出包线按平台裁剪**：

- 新增 `.github/Python/PrunePlatformScripts.py`
  - `windows-*` → 原样保留；
  - `ubuntu-*` / `macos-*` → 删除 `.bat` / `.cmd` / `.ps1`；
  - 重写 zip（临时文件 + `replace`），保留其余条目的 ZipInfo（时间戳 / 压缩方式不变）；
  - `--check-only` 提供「POSIX 包仍有 Windows 脚本 ⇒ 退出 1」的红/绿判据。
- 五条出包线在**生成 `AHA-PACKAGE.json` 之前**调用它：
  - `CliReleasePackageLeg.yml`（CLI-JVM）
  - `DesktopPackageLeg.yml`（桌面 JVM）
  - `NativeImageLeg.yml`（桌面原生）
  - `CliNativeImageLeg.yml`（CLI 原生，目前本就干净，作为统一口径与防御）
  - `BuildMvnArtifactLeg.yml`（Build 制品腿 / dev 预发行包）
- 入口断言改为按平台：
  - `CliReleasePackageLeg` / `BuildMvnArtifactLeg`：POSIX 只要求 `AhaCli.sh`，Windows 额外要求 `AhaCli.bat`；
  - `DesktopPackageLeg` / `BuildMvnArtifactLeg` 桌面端：POSIX 只要求 `AhaDesktop.sh`，Windows 额外要求 `AhaDesktop.bat`；
  - `DesktopPackageLeg` 另加「POSIX 包不得含 `.bat/.cmd/.ps1`」断言（裁剪后复查）。

**守卫**（`bin/CheckScripts.py`）：

- 新增 `check_platform_package_scripts()`：脚本必须存在；五条出包线都必须调用它且带 `--check-only`；
  `CliReleasePackageLeg` 不得再无条件要求 `AhaCli.bat`；
- `check_update_helper_packaging()` 的口径补充：描述符仍平台无关地收 helper（**Windows 包**需要），
  POSIX 包由出包线裁剪；输出文案改为「Windows 包必带 / git 跟踪 / 启动标记」。

**文档**：

- `Docs/DevSpec/ReleaseProcess.md` §3.6 改为「按平台分发」（v1.35.0）；
- `dist-desktop.xml` / `dist-native.xml` 中「非 Windows 包里带 `.cmd`/`.ps1` 属于暂时用不上」的注释
  改为「按平台分发」。
