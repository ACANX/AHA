## 关键决定

1. **进行中纯文本、收尾后富文本**：流式期间不解析（每 token 重建 AST 会卡），
   段收尾时解析一次；`finishedSeqs` 记录哪些段已收尾，`renderSegment` 据此决定是否替换节点。
2. **配色走 `themed`**：渲染器不自己缓存颜色，`StyleApplier` 传的是「延迟求值的样式字符串」，
   主题切换时 `restylers` 重新执行，富文本自动换色，不需要重建节点树。
3. **原文存在气泡属性里**（`aha.markdown.raw` / `rich` / `plain`）：菜单动作从属性取数据，
   避免闭包捕获流式期间的旧快照。
4. **链接点击 = 复制**：`AhaDesktopLauncher` 不继承 `Application`，拿不到 `HostServices`；
   `java.awt.Desktop` 在原生镜像里可用性未知，先做安全兜底（复制），后续再决定是否打开浏览器。
5. **表格用 `ScrollPane` + `GridPane`**：桌面端取横向滚动，不压缩列宽（与终端相反）。
