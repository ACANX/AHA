## 🔧 技术要点

### 关键决策

- **tag 小写、名称大写**：tag 用 `V<版本>-aha-<product>-<form>`，与 `ChannelContract.tag(BETA, …)` 逐字一致
  （客户端零改动即可识别），也与原生 dev 线（`-aha-desktop-native`）同风格；名称用
  `V<版本>-AHA-<目标>`，是用户在发布页看到的标题。
- **不用大写 `-AHA-` 做 tag**：`SnapshotCleanup.yml` 与 `Release.yml` 的排除规则都按 `-AHA-<目标>`
  识别快照；dev 线若用大写会与快照 tag 撞车，故 tag 保持小写。
- **旧 tag 只做「读」兼容**：不再新发 `-aha-jvm`，但 `ChannelContract`、`UpdateJvm.ps1` 都保留解析，
  历史 release 与旧命令行（`-Tag …-aha-jvm`）继续可用。
- **部分可用语义不变**：某形态全部腿失败 ⇒ 只发有产物的那一条，另一条不建空 release。
