## 🔧 技术要点

### 关键决策

- **渲染层读旧内容**：Issue 明确「不改变编辑工具本身的执行逻辑」，
  因此由 `StreamRenderer` 在调用前读取文件快照，工具仍按原逻辑写入；
- **上下文 3 行**：与常见 unified diff 默认值一致，兼顾可读性与屏幕占用；
- **前缀优先于颜色**：无颜色 / 低色终端必须仍能区分新增与删除。

### 边界

- 文件不存在（纯新增）：旧内容为空，全部显示为 `+`；
- 新内容为空（纯删除）：全部显示为 `-`；
- 大文件中间段做 LCS 时限制规模，超出退化为全删全增；
- 读取旧内容失败（权限 / 二进制）：当作无旧内容。
