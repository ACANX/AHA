## 🔧 技术要点

### 关键决策

- **内边距也是底色**：上下空行与每行首列都用同一 `blockLine` 铺底，
  否则内边距会变成无色空隙，色块被切断；
- **行首缩进统一在 `ToolBlock` 内完成**：`head` / `result` 手动加 1 空格，
  `details` / `body` 通过 `INDENT` 调整，避免 `StreamRenderer` 里再拼字符串；
- **宽度按可见字符计算**：`Style.fillBlock` 已剥离 ANSI 后补齐，前导空格也计入可见宽度。

### 边界

- 无色终端：`blockLine` 原样返回，`padding` 为空串（不插入空格）；
- `width <= 0`：只加底色不补齐。
