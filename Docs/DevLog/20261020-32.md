## 关键决定

1. **每格只画「上 + 左」，末行补下、末列补右**：这是唯一能保证「所有线都是 1px」的画法。
   若每格四边都画，相邻两格的内线各 1px ⇒ 视觉 2px，与外框 1px 不一致。
2. **`hgap` / `vgap` 归零、内边距改用 `-fx-padding`**：`GridPane` 的 gap 会在相邻格之间留空隙，
   边框看上去是断的；把间隙做成单元格内边距，边框才能连续贴在一起。
3. **颜色经 `styler` 延迟求值**：`Palette` 是可变静态字段，只有 `styler`（`DesktopShell#themed`）
   能在主题切换时重新求值；直接读 `Palette.BORDER` 拼字符串只会在首次渲染时取到旧色。
4. **不动列宽算法与横向滚动**：边框绘制只加样式，不改变 `GridPane` 的测量逻辑，
   超宽表格仍然横向滚动。
