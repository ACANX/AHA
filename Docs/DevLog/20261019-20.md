## 🔧 技术要点

### 关键决策

- **先折行再统计**：旧实现边遍历边截断，无法得到折行后的总行数；
  改为先收集全部折行结果，再取前 N 行，提示中的「共 M 行」才与终端一致；
- **成功 / 失败统一阈值**：Issue 说的是「单块内容」而不是「成功预览」，不再区分 5 / 40 行；
- **回灌隔离**：折叠只发生在渲染层，`AgentEngine` 回灌的是原始 `outcome.display()`。

### 边界

- 空输出 / 纯空白：返回空列表，不产生折叠提示；
- `maxLines <= 0`：全部折叠（保留提示），调用方目前不会传 0。
