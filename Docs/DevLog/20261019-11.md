## 🔧 技术要点

### 关键决策

- **只修「表格后第一行」的复位，不改「空行终止表格」**：当前实现把表格后的空行吞进 `tableRows`
  （`TableRenderer` 会跳过全空行），所以源文档里表格与 `###` 之间的空行在输出中消失，两张
  以空行分隔的表格也会被并成一张。这属于另一个语义问题，改动会改变既有输出行距，超出本次范围，
  留作后续单独处理（见「待办事项」）。
- **复位放在 `flushTable()` 而不是 `stepTable()`**：`flushTable()` 同时被流结束的 `flush()` 调用，
  放在这里两条路径都覆盖。
- **`lastEmitted = '\n'`**：表格渲染结果以换行结尾，若不更新，`_` 的词内判定会把表格前的字符当作
  前一字符，可能把表格后第一行的 `_x_` 误判为词内下划线。

### 核心代码

```java
private void flushTable() {
    if (tableLine.length() > 0) {
        tableRows.add(tableLine.toString());
        tableLine.setLength(0);
    }
    inTable = false;
    if (!tableRows.isEmpty()) {
        out.append(TableRenderer.render(tableRows, style, width, box));
        tableRows.clear();
        lastEmitted = '\n';
    }
    resetLineState();
}

private void resetLineState() {
    kind = LineKind.PLAIN;
    headingLevel = 0;
    prefix.setLength(0);
    prefixDone = false;
    pendingHasDelimiter = false;
}
```
