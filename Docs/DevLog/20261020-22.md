## 🔍 为什么「第一个键」而非硬编码默认

`ThinkingLevelMap` 是「强度 → 供应商参数值」的映射，没有「当前值」语义。
用 YAML 保序的第一个键作默认，好处是：

- 配置写 `Max: max` 在前，用户意图就是「默认用 Max」；
- 不引入新的全局默认（避免 `Aha.yaml` / `Model.yml` 两处配置打架）；
- 想显式指定时写 `ThinkingLevel`，语义清晰。
