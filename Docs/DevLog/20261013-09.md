## 🔧 技术要点

### 关键决策

- **序号怎么定**：原文件名只有年月、没有序号，因此重编序号需要一个确定依据。选
  **原索引表的登记顺序**——它已经是按事件时间排好的，用它既不需要重新考古，又让
  「编号顺序 = 时间顺序」这条可读性最强的性质成立。
- **`Pr15StaleLocalRef` 为什么是 `PR-15-Stale-Local-Ref`**：`PR` 属规范列明的可整体大写的
  专有缩写；`15` 是编号而非单词，故写成 `PR-15`。
- **H1 只留编号**：规范要求 `# TS-<编号> · <中文标题>`。若连英文词序一起写进 H1，
  会与文件名重复；故 H1 收成 `TS-2610-NNN · 中文标题`。
- **历史变更日志不回改**：`DocumentationSpec.md` v1.15.0 / v1.18.0 / v1.20.0 与
  `AHA-Design-V1.md` v3.67.0 里出现的 `TS-yyyyMM-…` 是**当时的事实记录**，保留原文；
  新格式由 v1.22.0 一条交代前后变化。这与规范 §3「追加式更新」一致。
- **冻结文件里的链接要改、内容不加**：`TODO.md` / `PLAN.md` / `Dbsx.txt` 冻结的是「不再新增
  待办与进展」，而改名会让其中的引用 404（`CheckDocs.py` 的链接检查会失败），
  因此**只做引用替换与格式口径同步，不追加任何内容**。
