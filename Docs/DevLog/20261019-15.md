## 📋 任务概述

把状态行从「等待 / 工具 / 空闲」三态扩展为 **#342 要求的七态状态机**：

| 状态 | 触发 | 展示 |
|---|---|---|
| 空闲 | 回合结束 / 中断后 | 静态三项 |
| 请求中 | 回合开始 | `⠋ 请求中…` + 实时耗时 |
| 生成中 | 首个正文增量 | `⠋ 生成中…` |
| 工具执行中 | 工具调用事件 | `⠋ 执行工具 <名>…` + 实时耗时 |
| 等待审批 | 审批问答开始 | `⠋ 等待审批…` |
| 完成 | 流正常结束 | `✓ 完成`（保留 2s） |
| 失败 | ERROR 事件 | `✗ 失败 · 单行原因`（保留 2s） |

## 🔧 技术要点

### 关键决策

- **状态切换立即绘制**：不等下一个 tick，验收要求 ≤200ms；
- **完成/失败保留 2 秒**：用户需要看到「这轮结束了没、失败原因是什么」，随后自动回空闲（显示三项）；
- **失败只取首行**：堆栈与多行错误已在正文区呈现，状态行只留摘要；
- **审批回调走 `Renderer` default 方法**：`StatusLine` 保持包内私有，不为了回调把它暴露成公共 API。
