## 📋 任务概述

#357 / PR #360 已把配置字段 `Adapter` 改名为 `ApiType`，但 SPI 与运行期仍是旧命名：

| 位置 | 旧名 | 实际语义 |
|---|---|---|
| `LlmProviderAdapter.providerId()` | 供应商 ID | 适配器 / API 类型 |
| `OpenAiAdapter.PROVIDER_ID` 等 | 供应商 ID | 同上 |
| `LlmAdapterRegistry.providerIds()` | 供应商集合 | ApiType 集合 |
| `ProviderConfig.adapter()` | 适配器 | `ApiType` |

真正的「供应商」是 `Model.Providers.<Id>` 的键（`DeepSeek` / `Anthropic` …），
由 `RuntimeDescriptor.attributes["Provider"]` 表达，与 SPI 的 `providerId()` 不是一回事。
