## 📋 任务概述

围栏代码此前原样输出，长代码块难以扫读。本次按语言标识做**单行**语法高亮：
关键字 / 字符串 / 注释 / 数字；未知语言回退纯文本，无色终端不产生 ANSI。

## 🔧 技术要点

### 关键决策

- **只做单行**：Issue 明确不做跨行状态机；注释、字符串都在行内闭合，
  多行字符串 / 块注释的后续行按普通文本处理；
- **围栏行延迟到行尾**：语言标识（```java）只有整行读完才知道；
  若在第三个反引号时立即进入围栏，语言字符会被当成代码内容；
- **未知语言不猜**：直接原样输出，避免错误着色误导。

### 边界

- 未闭合围栏：`flush()` 时按当前语言高亮剩余内容；
- 围栏内的 `|`、`#`、`-` 等仍不会被当作 Markdown / 表格；
- 无色终端：`CodeHighlighter` 直接返回原行，零 ANSI。
