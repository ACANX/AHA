# 开发日志 2026-10-20 14:00

> 关联：issue #382 —— 桌面端 Ubuntu 包界面中文显示为方块（系统缺中文字体且应用无 CJK 回退与提示）
> 关联记录：`FontFallback`、`DesktopShell#rootStyle`、`AhaDesktopApp#logRenderingDiagnostics`

## 📋 任务概述

ACANX 在 WSL2 Ubuntu 26.04 上启动 `aha-desktop.jar`（`0.1.5.00380`）后，窗口正常出现、
但界面中文全是方块。取证结论：`fc-list :lang=zh` 为 0（本机没有任何含汉字字形的字体），
JavaFX 默认族 `System` → fontconfig → DejaVu Sans，合成字体回退也借不到中文字体。

结论：**环境是诱因，产品是缺陷** —— 应用既没做 CJK 回退，也没在缺字体时给出可操作提示。

## ✅ 方案

按 issue 的建议取 **A + B**（C 内嵌字体子集不做：增加 jar 体积、原生镜像要登记资源、
字体许可与版本维护成本；D 只对用脚本启动的人有效，信息仍会丢）：

1. **A. 字体回退链**：新增 `aha-desktop/.../view/FontFallback.java`
   - 候选顺序：`Noto Sans CJK SC` → `Source Han Sans SC`/`CN` → `WenQuanYi Micro Hei`/`Zen Hei`
     → `Droid Sans Fallback` → `AR PL UMing CN` → `Microsoft YaHei UI`/`YaHei` → `PingFang SC`
     → `Hiragino Sans GB`；
   - 只在 **Linux** 上替换全局字体（Windows / macOS 默认字体本就能显示中文，替换会改变西文观感）；
   - 精确候选全不命中时，用族名特征兜底（`CJK` / `Heiti` / `YaHei` / `WenQuanYi` 等）；
   - `DesktopShell#rootStyle()` 把选中族拼成根节点 `-fx-font-family`，子树继承；
   - 四处硬编码等宽字体（`LogPanel` / `DesktopShell.CODE_STYLE` / `OutputDialog` / `ApprovalDialog`）
     改为 `FontFallback.MONOSPACE_CSS`：CJK 候选插在通用族 `monospace` **之前**（放后面永远不会被选中）。
2. **B. 缺失显式提示**：启动时若 Linux 上一个 CJK 族都没有：
   - `LOG.warn` 一行；
   - 消息区（`appendNotice`）给出多行提示，含可复制的 `sudo apt install fonts-noto-cjk`；
   - `logRenderingDiagnostics()` 新增 `渲染诊断：中文字体 …`（平台 / 选中族 / 命中数量 / 缺失原因）。

**CLI 不纳入本单**：CLI 的汉字由终端字体决定，不在 AHA 控制范围内（#235 是控制台编码，另一回事）。
