## ✅ 完成内容

### 1 取件落地：版本目录留档 + 落地根平铺（甲）

`Dist/UpdateJvm.ps1` 新增第 5 件事：解压后把**去版本号**的入口**复制**到 `<Out>`（= `Dist\`）根。
入口表按种类声明（`$kinds[*].Flat`）：

| 种类 | 平铺的入口 |
|---|---|
| Desktop | `aha-desktop.jar`、`AhaDesktop.bat`、`AhaDesktop.sh` |
| Cli | `aha-cli.jar`（新形态的包根 jar，或旧形态的 `aha-cli-*.jar` 改名为无版本号）、`AhaCli.bat`、`AhaCli.sh`（平铺迁移后才会出现在包根）|

- 只复制**包根**的条目（不加 `-Recurse`）：旧形态的包把脚本放在 `bin\` 下，那不是平铺入口；
- 落地根被占用（进程正在跑）时给出明确提示，而不是抛原始 IO 异常；
- 新增 `-NoInstall`：只解压到版本目录，不平铺；
- 状态文件记下平铺了哪些入口；**平铺件被删掉时不再算「已是最新」**，会重解压补齐。

### 2 顺带修掉「静默退回旧版本」（独立 PR #220）

见 `Docs/DevLog/20261015-15.md` 之后的分析：`V0.1.3.00219-aha-jvm` 缺 Windows/jdk25 那条腿的资产
（Maven Central 403），旧实现于是**静默**退到 `00216`（`bin/` + `lib/` 旧形态、没有单体 jar），
用户以为拿的是最新版。现在只看最新一版、缺资产即报错并列出现有资产，退旧版必须显式 `-AllowOlder`。

## 🔧 技术要点

- **甲 / 乙 的取舍**：ACANX 原文说「**复制**到 `Dist` 目录下」，因此取甲 ——
  版本目录保持完整（多版并存、可回滚），落地根那份是「当前版」的复制，两者互不影响。
- **平铺是「复制 + 覆盖」，不是「移动」**：与原生包（`UpdateNative.ps1` 摘出 exe 覆盖）语义不同，
  这条差异已写进脚本头与速查表。
- **「已是最新」的判据要包含平铺件**：否则用户删掉 `Dist\aha-desktop.jar` 后，
  脚本会一直说「无需更新」，而他手上其实没有可运行的入口。
