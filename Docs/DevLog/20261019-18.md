## 📋 任务概述

工具调用已按块展示（块头 / 命令 / 明细 / 正文 / 末行），但**块内底色不一致**、
连续块之间缺少明确边界。本次让整块使用同一底色，并明确块间空行。

## 🔧 技术要点

### 关键决策

- **嵌套 ANSI 的处理**：行文本里已有 `muted` / `command` 的 `RESET`，
  直接外层包背景会被中途重置；`blockLine` 先去掉 `RESET`，最后统一收尾；
- **失败块不再换红底**：底色属于「块」而不是「行」，颜色语义交给前景色与 `✗`；
- **`currentKind` 只覆盖工具结果阶段**：错误事件与正文不铺工具底色。

### 边界

- 无色终端：`blockLine` 直接返回原文本，不插入任何 ANSI；
- `width <= 0`：只加底色不补齐（无法判断行宽）。
