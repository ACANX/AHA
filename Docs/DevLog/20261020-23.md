# 开发日志 2026-10-20 23:00

> 关联：issue #346 —— CLI 表格块边界（空行应终止表格，且表格与正文之间保留空行）

## 现象（#346）

1. 表格后的空行被吞掉：源里表格与 `###` 之间有一个空行，输出里没有，表格「上面对称、下面不对称」；
2. 空行不终止表格：两张表被并成一张，第二张表的单元格落到第一列。

## 根因

`aha-cli/.../render/MarkdownStream.stepTable()` 收到 `\n` 时**无条件**把当前行加入
`tableRows`。空行因此：

- 没有触发 `flushTable()` → 表格继续，下一张表的行被收进同一张表；
- 被 `TableRenderer.render()` 当成全空行跳过 → 输出里也没有它。

两个缺陷同源。

## 修复

```java
if (codePoint == '\n') {
    if (tableLine.length() == 0) {
        // 空行是 GFM 的表格终止符（issue #346）
        flushTable();
        endLine();
        return;
    }
    tableRows.add(tableLine.toString());
    tableLine.setLength(0);
    return;
}
```

- `flushTable()` 结算当前表（列宽独立）；
- `endLine()` 把这一空行按普通行输出，与表格前的空行对称；
- 表格后**直接接正文**（无空行）仍走「行首非 `|` → flushTable + step」的旧路径，
  #345 的 4 条回归用例不受影响。
