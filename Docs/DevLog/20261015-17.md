### 2 顺带修掉 #217 的同类问题（原生线也受益）

shade 顶替主产物时，凡是按「项目工件」取件的地方都会拿到单体 jar：

- 装配描述符的 `dependencySet`（`useProjectArtifact=true`）→ 包里同一个类存两遍（55MB）；
- `aha-cli-native` 声明了对 `aha-cli` 的依赖（`scope=runtime`）→ 拿到单体 jar，再叠上它自己
  `copy-dependencies` 拷的同一批依赖，classpath 上人人两份。

改成附带产物后，两条链路拿到的都是「模块 jar + 依赖 jar」，只有便携包用单体 jar —— 这与
桌面端在 #219 里定下的口径一致（`BuildSpec.md` §7 的硬约定）。

### 3 CI 自证（两道线都加）

- `BuildJVMArtifacts.yml`：CLI 步骤改为「打 zip → 拆开自证」——不得有 `lib/`、`bin/`；
  三个入口平铺在包根；单体 jar 的 `Main-Class` 是 `com.acanx.module.aha.cli.AhaCli`、
  无 `module-info.class`、含 picocli / sqlite-jdbc / log4j2 各自的代表类（证 shade 真合了依赖）；
  最后**真跑一次** `java -jar aha-cli.jar version` 并断言输出含本次版本号。
- `Release.yml`：CLI 侧同样自证；**发行包的版本段改由 `ProjectVersion.py --resolve` 读**——
  平铺后包内 jar 名不含版本号，原先「从产物名读版本」那条路没有了。
- `Release.yml` 的**桌面端完整性自证是 #219 的漏网**：它还在按旧形态判（`lib/javafx-*.jar` 数
  3 个、`bin/AhaDesktop.sh`、`--module-path` 探针），下次发版必红。本单一起改成平铺口径：
  入口平铺 + 单体 jar 的 `Main-Class`/无 `module-info`/含 JavaFX 类 + **本平台原生库点名**
  （`linux` ⇒ `libglass.so`、`win` ⇒ `glass.dll`、`mac-aarch64` ⇒ `libglass.dylib`，且不得混进
  别的平台的库）。

### 5 取件落地后自动清理暂存目录（ACANX 追加要求）

「下载解压保存完成后需要自动清理 `Dist` 目录下的 `desktop-jvm` / `cli-jvm` 目录，
对于原生镜像包，如果存在类似的问题也要调整掉。」

- `Dist/UpdateJvm.ps1`：平铺成功后删掉解压出来的 `<种类>\<版本>\`（父目录空了也一并删），
  并报出省下多少 MB；新增 `-KeepExtract` 明说保留。「已是最新」的判据随之改到**落地根的入口**上
  —— 暂存目录被清掉后，再拿它当判据会让每次运行都重下一遍。
  - 只在**至少铺出一个入口**后才删：旧形态的包（包根没有单体 jar）一个入口也铺不出来，
    那份解压结果就是唯一能用的东西。
- `Dist/UpdateSnapshot.ps1`：原生快照把 exe 装进落地根后，解压目录同样是重复副本 ⇒ 清掉
  （zip 留着，要再解一份随时可解）。JVM 快照没有可安装的 exe，解压目录本身就是要跑的东西，**保留**。
- `Dist/UpdateNative.ps1`（dev 线原生）**本来就干净**：解压走 `GetTempPath()` 下的临时目录，
  在 `finally` 里删掉，落地根只留 exe 与 `.bak`。查过，无需改动。
- 文档：速查 §2.4（落地只剩一处 + `-KeepExtract`）、§3.1、§6；`CHANGELOG` 对应条目。

## 🔧 技术要点

- **一条命令只做一件事**：`copy-fatjar-to-dist` 与装配描述符的 `file` 做的是同一件事，
  改完后删掉前者 —— 两个地方都写，早晚有一个先过期。
- **入口脚本的「旧形态」判定要给出路**：用户 `Dist/` 里很可能还留着旧 zip，
  解压出来没有 `aha-cli.jar` 时报「找不到主类」会让人以为是 JDK 问题；现在直接点明
  「这是 #218 之前的旧形态包」，并给出重新构建 / 取新包的指引。
- **`mvn dependency:tree` 不再是唯一的依赖查看方式**：平铺后包里没有 `lib/`，
  但需要审计依赖时读依赖树即可（`BuildSpec.md` §7 已改口径）。
