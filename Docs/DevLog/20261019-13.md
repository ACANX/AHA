## 🔧 技术要点

### 关键决策

- **旧标签不删**：删标签会把历史 PR 上的标记一起抹掉（GitHub 行为），
  历史可追溯性优先；改为「停用 + 描述指引」。
- **历史文档不改**：Troubleshooting / DevLog / CHANGELOG 的历史段落记录的是当时事实，
  保留旧名并由守卫按路径豁免；这样既不改写历史，又不会让活代码漏改。
- **守卫不放松**：新增的是「历史路径豁免」，不是「旧名放行」——
  同样的旧名出现在 `Docs/Guide/**` 或 `.github/**` 仍会判红。
