# 开发日志 2026-10-20 18:00

> 关联：issue #393 —— WSL 中桌面原生镜像加载到界面后 JNI FatalError 退出
> 关联记录：`jni-config.json`、`NativeImageMetadataTest#jniConfigRegistersPiscesSoftwareRendererClasses`

## 📋 任务概述

WSL2（WSLg，无 GPU）上启动 `aha-desktop` **原生镜像**：窗口刚出现、日志已打
`[ui-fxml-loaded] desktop-shell.fxml`，随后直接 abort：

```text
Prism pipeline name = com.sun.prism.sw.SWPipeline
Initialized prism pipeline: com.sun.prism.sw.SWPipeline
[ui-fxml-loaded] desktop-shell.fxml
Fatal error reported via JNI: Failed to throw an exception!
  A com.oracle.svm.core.code.IsolateEnterStub.JNIFunctions_FatalError_...
  A com.sun.pisces.JavaSurface.initialize(Native Method)
  i com.sun.pisces.JavaSurface.<init>(JavaSurface.java:45)
  i com.sun.prism.sw.SWRTTexture.<init>(SWRTTexture.java:51)
  i com.sun.prism.sw.SWResourceFactory.createRTTexture(SWResourceFactory.java:136)
  A com.sun.javafx.tk.quantum.UploadingPainter.run(UploadingPainter.java:125)
```

## 🔍 根因

- 无 GPU 时 Prism 回退到 **SW pipeline**，第一次 `UploadingPainter` 会创建 `SWRTTexture`，
  其构造器 new `com.sun.pisces.JavaSurface`，调用 `native void initialize(...)`。
- 解包 JavaFX 25 linux 的 `libprism_sw.so` 后 `strings` 可见：native 用**静态 JNI 命名绑定**
  （`Java_com_sun_pisces_JavaSurface_initialize`、`..._PiscesRenderer_initialize`、
  `..._AbstractSurface_getRGBImpl` 等），并 `GetFieldID` 查
  `nativePtr`（J）、`dataInt`（[I）、`surface`（Lcom/sun/pisces/AbstractSurface;）。
- 这些类**从未进过 `jni-config.json`**（原清单只覆盖 Glass / 字体 / D3D / Path2D 等）。
  Native image 里未登记的 JNI 字段/方法拿不到 ID，随后 `JNIUtil.JNI_ThrowNew` 也失败
  （`java.lang.OutOfMemoryError` 同样未登记，`FindClass` 失败），最终 `FatalError` 直接 abort。
- 与 #383 的关系：#383 修复前原生包在更早的 `ConfigLoader` 就崩，根本走不到绘制；
  修复后 SW 渲染路径暴露，这是**独立的下一个缺口**，不是回归。
- 也解释了此前 CI Linux 原生冒烟退出码 134（SIGABRT）：同一 SW pipeline 路径。

## ✅ 修复

`aha-desktop/src/main/resources/META-INF/native-image/com.acanx.module.aha/aha-desktop/jni-config.json`
新增 5 条（均 `allDeclaredConstructors/Methods/Fields`）：

| 类 | 用途 |
|---|---|
| `com.sun.pisces.AbstractSurface` | `nativePtr` 字段、`getRGBImpl` / `setRGBImpl` native 方法 |
| `com.sun.pisces.JavaSurface` | `dataInt` 字段、`initialize` native 方法 |
| `com.sun.pisces.PiscesRenderer` | `nativePtr` / `surface` 字段、多个绘制 native 方法 |
| `com.sun.pisces.Transform6` | `initialize` native 方法 |
| `java.lang.OutOfMemoryError` | `JNIUtil.JNI_ThrowNew` 的 `FindClass` 目标 |

守卫：`NativeImageMetadataTest#jniConfigRegistersPiscesSoftwareRendererClasses()`
逐个断言类名存在且 `allDeclaredMethods` + `allDeclaredFields` 齐全，并检查
`java.lang.OutOfMemoryError`。漏一个就红。
