## 📋 任务概述

按 #269 的拍板口径，把「发布物」从「两套命名 + 发布页代码里硬编码」收敛成
「一套文法 + 矩阵单一来源」：

- 资产名文法：`aha-<product>-<form>-<version>-<os>-<arch>-<runtime>.zip`；
- tag：`V<版本>-aha-<product>-<form>`（Beta）/ `V<版本>-AHA-<product>-<form>-SNAPSHOT`（Alpha）；
- Stable 一个 release 装下 **4 组合 × 3 平台 = 12 份**资产；
- CLI-JVM 三平台三个名字（内容暂相同）；
- 原生形态自 0.1.4 起进 Stable；
- 旧名（0.1.3 的 `aha-desktop-…` / `AHA-Desktop-Native-…`）兼容一个周期，0.1.5 起守卫判红。
