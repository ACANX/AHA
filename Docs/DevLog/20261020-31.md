## 关键决定

1. **白名单 HTML 只做三个标签**：`br`（表格单元格唯一可用的换行写法）、`sub`、`sup`。
   `<span>` / `<script>` 一律不进 AST，退化成普通文本——不执行、不套样式、不丢内容。
2. **裸 URL 终止符先中文标点再英文标点**：中文标点直接终止（不可能出现在 URL 里）；
   英文 `.,;:!?)]'` 先吞进候选再回退，避免「句末句号被链接吃掉」。
   代码段由反引号分支先消费，围栏在块级已隔离，所以「代码内不识别」是结构上成立的。
3. **`<sub>` / `<sup>` 用 `baselineOffset` 而不是嵌套 `TextFlow`**：嵌套会让行高与基线都难对齐，
   而上下标里再套粗体属于极少数场景，取舍为「拍平成文本 + 缩小字号」。
4. **不支持项写成文档而不是「尽力渲染」**：脚注 / 定义列表 / 数学 / mermaid 都保留原文，
   兜底测试断言的是「原文完整可见」，不是「渲染成什么」。
