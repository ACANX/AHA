## 📋 任务概述

用户反馈 `V0.1.5.00380.10200208-AHA-Desktop-JVM` 已出包，但桌面端「检查更新」查不出来。

## 🔍 原因

快照 tag（2026-10-17 起）格式为 `V<5 段版本>-AHA-<目标>`，目标词是**大写驼峰**
（`Desktop-JVM`），而 `ChannelContract` 的解析与生成都用了小写 `tagSuffix()`
（`desktop-jvm`）：

```java
case ALPHA -> "V" + version.value() + SNAPSHOT_TARGET_INFIX + kind.tagSuffix();
```

于是 `versionOfTag(ALPHA, DESKTOP_JVM, "V0.1.5.00380.10200208-AHA-Desktop-JVM")`
返回空，`ReleaseFilter.select` 把该 release 过滤掉，检查更新自然看不到。

## ✅ 完成内容

- [x] `ChannelContract.tag(ALPHA, ...)` 改用 `kind.targetWord()`（大写驼峰）；
- [x] `versionOfTag(ALPHA, ...)` 的候选模式同时接受：
  - `V<ver>-AHA-Desktop-JVM`（当前实际格式）；
  - `V<ver>-AHA-desktop-jvm`（曾生成过的小写格式）；
  - 旧的带 `-SNAPSHOT` 后缀写法（大小写两种）；
- [x] `ChannelContractTest`：
  - 生成断言改为大写 `-AHA-Desktop-JVM` / `-AHA-Cli-Native`；
  - 新增实际出包 tag 的解析断言与小写兼容断言。
