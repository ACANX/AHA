## 🔧 技术要点

### 关键决策

- **「不碰评论」不等于「不出错」**：早先为避免覆盖原生线/自己的旧评论而选择 `owns_comment=False`，
  代价是**错误文案长期残留**。修复方向是「写上准确的内容」，而不是「什么都不写」；
- **可以覆盖自己那条旧评论**：跨线意味着本次请求不含本线目标，把「未打任何标签」（错误）
  改成「属 X 线，交由 X 处理」（正确）是净改善；只动**自己的** marker，两条线分离的约束不变；
- **「未打标签」归 JVM 线**（`TS-2610-042` 定）与「跨线写交接」不冲突：前者管无标签、后者管有请求但属他线。
