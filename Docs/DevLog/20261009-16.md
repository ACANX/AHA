## 🔧 技术要点

### 关键决策

- **日志装配用程序化配置而非 `log4j2.xml`**：JPMS 下 `getResources` 不搜模块路径；配置文件读不到，
  必须显式对当前 context 应用配置（`LoggingSetup.install`）。
- **`${AHA_HOME:-.}` 的 fallback 改 `~/.aha`**：默认落点应是用户级目录，项目目录属显式自定义。
- **原生镜像走 profile 隔离**：默认路径一旦依赖平台工具链，失败原因会从「代码问题」变成「环境问题」，
  在别人机器上极难复现。
- **构建报告不进镜像包**：报告是调优依据，体积与镜像目标不同，独立成包更清晰。
- **「构建成功」不是验收标准**：容忍失败必须以「叫得响」为条件，否则等于把红叉换成静默空转。
