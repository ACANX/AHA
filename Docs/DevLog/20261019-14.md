## 🔧 技术要点

### 关键决策

- **模式排最前**：它最短，也是「切错后后果最重」的一项；宽度不足时宁可丢目录也不丢模式。
- **档位而不是编造的「低/中/高」**：思考强度取运行时 `Tier`（Ultra / Pro / Standard / Flash / Fallback），
  未配置时只显示模型名——不把猜测值写进状态栏。
- **严格模式通过权限策略实现**：不新增一套审批逻辑，而是取消自动放行，让现有
  `ConsoleToolApprover` 自然接管（含 READ）。
- **`a` 的回调用 `Runnable`**：`ConsoleToolApprover` 只知道自己「刚放开了某个权限」，
  由调用方决定状态栏怎么显示，避免渲染层反向依赖审批器。
