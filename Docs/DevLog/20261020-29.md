## 关键决定

1. **词法放 `aha-core` 而不是 `aha-cli`**：`aha-desktop` 不依赖 `aha-cli`（依赖矩阵是
   core ← tool ← desktop，与 cli 平行）。要复用就只能下沉到 core；`core.markdown` 包已在
   S1.1 里 exports 过，不需要再动 `module-info`。
2. **不改 CLI 输出**：`CodeHighlighterTest` 用 `contains` 断言颜色与文本，重构后必须仍然全绿——
   这是「提炼中间结构」的安全网，先动结构不动行为。
3. **`TextFlow` 而不是 `Label`**：一个 `Label` 只有一个颜色；`TextFlow` 里每个 token 一个 `Text`，
   各自 `-fx-fill`。不设宽度约束 → 长行由外层 `ScrollPane` 横向滚动，不折行。
4. **颜色映射取现有 `Palette`**：关键字 `WRITE`、字符串 `SUCCESS`、数字 `EXEC`、注释 `MUTED`。
   不新增主题色，避免主题文件与 `Palette` 两处定义漂移。
