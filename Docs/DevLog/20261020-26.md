## 设计要点

1. **AST 不含 JavaFX**：解析器因此能在无头环境断言（CI 直接跑），渲染留给 S1.5；
2. **列表用扁平缩进**（`ListItem.indent`）而不是递归嵌套：断言简单，也不会因异常缩进构造出深树；
   渲染时（S1.3）按相邻缩进分组；
3. **表格只认「表头 + 分隔行」**：没有分隔行的 `|` 行留在段落里（与「不吞内容」一致）；
   分隔行要求每列 ≥3 个 `-`（GFM 口径）；
4. **引用递归解析**内部文本，嵌套引用自然成立；
5. **未闭合围栏**一直吃到段尾（与 CLI 一致）。

## 与 CLI 的关系

两端共用 `MarkdownSemanticsSamples`：CLI 断言渲染输出，桌面断言 AST 类型。
S1.1 的桌面断言到「块类型」为止；行内标记的断言在 S1.2 补。
