## 需求

### 1. 输入框样式与 loading 动效（`Dbsx.txt` §3）

- 行首不再打印 `aha>`，改为在输入行上下各加一条制表符／分隔线，把输入行包成输入框（对标 pi / Claude Code）；
- 支持动态 loading 旋转字符，直观提示「可在此输入」。

### 2. 底部状态栏（`Dbsx.txt` §4）

输入框下方展示：

- 当前模型与思考强度；
- 当前工作目录；
- 本次会话上行 / 下行 / 总 token 数、缓存命中率；
- 当前上下文占比与模型最大上下文长度；
- 当前 agent 运行模式（自动 / 完全授权 / 严格）。

### 3. 斜杠命令与下拉补全（`Dbsx.txt` §5）

支持在输入行输入 `/` 开头命令并给出下拉候选：压缩上下文、查看设置、切换模型、调整思考强度、查看工具与上下文信息等。

## 已知前置条件（重要）

- **状态行位置**：`PLAN.md` §1 已记录两次尝试失败（提示符重绘与 `printAbove` 共享显示状态，正文会静默消失），结论是位置只能选「输入行下方」或自研底部渲染（路径 C）。**不要再重试 A/B 的刷新式方案**。
- **token / 缓存 / 上下文数据源不存在**：`UsageEvent` 目前只在流式过程中发出，从不持久化，SQLite 无 usage 表；用量统计整体安排在 **0.6**。状态栏的用量部分需等 0.6 用量落库后才能做，界面先行可只留占位。

## 验收标准

- [ ] 输入行无 `aha>` 前缀，上下包裹成输入框；有 loading 动效；
- [ ] `/` 输入即出下拉候选，方向键 / Tab 选择，Enter 接受；命令在本端执行、不发往模型；
- [ ] 状态栏展示模型与思考强度、工作目录、运行模式；用量四项在 0.6 落库后补齐；
- [ ] conhost 等能力不足终端自动降级，不花屏。
