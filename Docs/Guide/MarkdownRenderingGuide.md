# 桌面端 Markdown 渲染支持矩阵

**文档版本**：v1.0.0
**状态**：草案
**生效日期**：2026-10-20
**最后更新**：2026-10-20
**负责人**：@ACANX
**适用版本**：AHA 0.2.x

---

## 1. 范围

桌面端（`aha-desktop`）把**助手输出**的 Markdown 渲染为 JavaFX 富文本，同时**保留原始 Markdown**
（查看 / 复制 / 导出）。渲染层只读：不修改模型输出，也不改写会话数据。

本文是支持的**唯一口径**：实现与本文不一致时，以本文为准并修实现（或改本文并说明理由）。
跟踪母 issue：`#408`。

## 2. 支持矩阵

### 2.1 块级

| 语法 | 渲染 | 说明 |
|---|---|---|
| 段落 | `TextFlow` | 段内软换行保留；空行分段 |
| `#` ~ `######` | 字号 19 / 17 / 16 / 15 / 15 / 15 px，全部加粗 | — |
| `---` `***` `___` | `Separator` | 颜色取主题边框色 |
| ` ``` ` 围栏 | 语言标签 + 「复制」按钮 + 等宽代码块 | 超过 30 行默认折叠 |
| `-` `*` `+` 无序列表 | `•` + 内容，缩进 14 px/级 | 支持缩进层级 |
| `1.` 有序列表 | 编号（保留起始号） | — |
| `- [ ]` / `- [x]` / `- [X]` | `☐` / `☑` / `☑` | **只读**，点击不改变状态 |
| `>` 引用 | 左侧 2 px 竖线 + 内容弱化色 | 支持嵌套 |
| 表格 | `GridPane` | 支持 `:---` / `:---:` / `---:` 三种对齐、缺列补空、单元格内行内样式；超宽横向滚动，不压缩列宽 |

### 2.2 行内

| 语法 | 渲染 | 说明 |
|---|---|---|
| `**粗**` `__粗__` | 加粗 | 侧翼规则与 CLI 一致 |
| `*斜*` `_斜_` | 斜体 | `snake_case_name` 不误判 |
| `***粗斜***` | 加粗 + 斜体 | — |
| `~~删除~~` | 删除线 | — |
| 行内代码 | 等宽 | 代码内不再解析 |
| 行内链接（方括号文本 + 圆括号地址） | `Hyperlink` | 点击**复制 URL**（不打开浏览器，见 §7） |
| 裸 URL（`http://` / `https://`） | 同 `Hyperlink` | 遇空白、`<`、`>`、引号、中文标点终止；尾部英文标点回退 |
| 4 个及以上连续 `*` / `_` | 字面量 | 不拆成「1 个 + 粗斜 + 1 个」 |
| `<br>` `<br/>` `<br />` | 换行 | 白名单 HTML |
| `<sub>` / `<sup>` | 缩小字号 + 基线偏移 | 白名单 HTML，标签名大小写不敏感 |
| 图片 | 占位「🖼 alt（点击加载）」 | 点击后才加载；`file:` / `https:` 放行 |

## 3. 明确不支持（按字面量展示，不吞内容）

| 语法 | 当前行为 | 原因 |
|---|---|---|
| 反斜杠转义（`\*`） | 原样显示 `\*` | 未实现；语义样本里 3 条 `escape-literal` 仍为 `pending` |
| 脚注（`[^1]`） | 原样显示 | 需要引用收集与文末列表，收益低 |
| 定义列表（`术语` + `: 定义`） | 按普通段落 | 同上 |
| 数学公式（`$…$`、`$$…$$`） | 原样显示 | 需要额外排版引擎 |
| mermaid 围栏 | 按未知语言代码块（单色） | 不引入渲染引擎；内容完整可见 |
| 白名单外 HTML（`<span>`、`<script>`…） | 标签与内容都原样显示 | 不执行、不套样式、不丢弃 |
| `http:` / `data:` / 无协议图片 | 拦截并说明原因 | 白名单只放行 `file:` 与 `https:` |

> 兜底原则：**不支持可以，吞内容不行**。四类不支持语法各有至少一条测试
> （`MarkdownUnsupportedTest`），断言原文完整可见。

## 4. 与 CLI 的差异

| 项 | CLI | 桌面端 |
|---|---|---|
| 表格超宽 | 压缩列宽 | 横向滚动（`ScrollPane`） |
| 代码高亮 | ANSI 颜色 | JavaFX `Text` 着色，**同一份词法**（`CodeLexer`） |
| 长代码折叠 | 工具输出折叠 | 30 行阈值，「已折叠 N 行」 |
| 图片 | 不渲染 | 占位 + 点击加载 + 白名单 |
| 链接 | 显示 URL | `Hyperlink`，点击复制 URL |
| 流式 | 逐 token 渲染 | 进行中纯文本，**段结束**才解析一次 |

## 5. 原始 Markdown 的四个入口

在**助手气泡**上右键：

| 菜单项 | 行为 |
|---|---|
| 查看原文 | `OutputDialog` 展示该段原始 Markdown |
| 复制 Markdown | 写入剪贴板 |
| 导出为 .md | 文件选择器，UTF-8 写入 |
| 切换原文 / 渲染 | 气泡内就地切换，便于对照 |

原文以气泡属性保存（`aha.markdown.raw`），不依赖渲染结果反推。

## 6. 验收样本

`#408` 下有 3 条评论可直接使用：

1. **期望表现**：样本 + 逐项对照表 + 真机检查清单；
2. **纯样本（代码块）**：便于整块复制；
3. **纯样本（直接渲染）**：作为 GitHub 渲染的对照基准。

## 7. 已知限制

1. **链接不打开浏览器**：`AhaDesktopLauncher` 不继承 `Application`，拿不到 `HostServices`；
   `java.awt.Desktop` 在原生镜像中的可用性未验证，因此先做「复制 URL」兜底。
2. **图片无缓存**：每次点击各自加载，重复点击会重复请求。
3. **HTML 白名单很窄**：只有 `br` / `sub` / `sup`，其余一律字面量。
4. **表格单元格内不支持块级元素**（列表、围栏、引用），只支持行内与 `<br>`。
5. **折叠阈值不可配置**（固定 30 行）。
