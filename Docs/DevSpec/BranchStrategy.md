## 分支模型

| 分支 | 用途 | 生命周期 |
|---|---|---|
| `main` | 稳定版本 | 永久 |
| `dev` | 开发主线 | 永久 |
| `feat/*` | 新功能 | 合并后删除 |
| `fix/*` | 修复 | 合并后删除 |
| `release/*` | 发布准备 | 发布后删除 |
| `hotfix/*` | 紧急修复 | 合并后删除 |

## 合并规则

- 功能分支从 `dev` 拉出，合回 `dev`
- `release/*` 从 `dev` 拉出，合回 `main` 与 `dev`
- `hotfix/*` 从 `main` 拉出，合回 `main` 与 `dev`
